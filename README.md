**Simple OSINT Tool**

Simple OSINT Tool is a Python-based project designed to explore Open-Source Intelligence (OSINT) techniques, with a focus on phone number lookups.

 **Status: Work in Progress**

This project is still under development and contains several bugs and incomplete features. Areas such as links.py and the email lookup functionality still need debugging and improvement.

**Features**

* Phone number lookups
* Discovery of publicly available information associated with phone numbers
* Exploration of OSINT techniques using Python

**Privacy & Security**

During testing, I discovered that looking up a phone number could reveal sensitive personal information, including home addresses, relatives, and associated phone numbers. This experience highlighted how much personal information can be exposed through publicly accessible sources.
